거래원장 분석 대시보드

웹사이트 게시본
- 주소: https://nanalab.kr/astra/dashboard/
- 메인 실습 사이트 목록의 레시피 29 카드에서 열 수 있습니다.
- 로고와 공통 서식은 Astra Playground 사이트에 맞춰 추가했습니다.
- 아래의 오프라인 실행 설명은 원본 배포본 기준입니다. 웹 게시본은
  공통 서식 ../assets/site.css와 온라인 로고를 사용하지만, 데이터 분석은
  외부 API 없이 브라우저에서 수행합니다.

실행
1. ZIP 파일을 폴더에 모두 압축 해제합니다.
2. index.html을 Chrome 또는 Edge에서 엽니다.
3. 별도 서버, 설치, 인터넷 연결은 필요하지 않습니다.
   HTML 파일만 옮기지 말고 CSS, JS, modules 폴더를 함께 보관하세요.

포함 내용
- 거래원장_8000건.xlsx의 거래내역 A1:E8001을 읽은 8,000건 스냅샷
- 기간 / 거래 구분 / 부서 / 결제수단 필터
- 집단 비교 기준 선택과 모든 분석 재계산
- 주요 지표, 추세, 분포, 부서별 비중, 분석 상태
- 96개 분석 항목의 실제 JavaScript 계산, 설명, 조건, 참고 출처
- 분석 라이브러리 카드에 결과 그래프 표시, 클릭하면 확대와 상세 해석
- 기본 범위의 결과 90개 모두 그래프 제공; 제외 항목은 사유 표시
- 원본 Excel 행 번호가 있는 거래 조회
- 분석 요약 CSV, 선택 거래 CSV, 개별 그래프 SVG 저장

분석 범위와 상태
96은 통계량, 시각화, 검정, 모형 변형, 진단을 나눈 항목 수입니다.
독립적인 통계분석 기법 96종이라는 뜻은 아닙니다.
실행 완료: 선택 범위의 계산이 끝났습니다. 통계적 유의성을 뜻하지 않습니다.
조건부 결과: 계산값과 함께 표본, 모형 가정, 재표집 또는 검증 범위의 제한을 제공합니다.
제외됨: 자료 조건 또는 구현 실행이 실패한 항목이며 다른 기법으로 대체하지 않습니다.

원장 기본 범위의 초기 실행 결과
44개 실행 완료 + 46개 조건부 결과 + 6개 제외 = 96개 항목
16 구성비 표준화: 일부 비교 월에 신규 부서 매출이 없음
17 구성 효과 분해: 일부 비교 월에 신규 부서 매출이 없음
36 오즈비: 특정 필터에서 변동이 없는 교차표에 잘못된 보정값을 반환한 문제
48 Huber 강건회귀: 초기 구현의 실행 성능 문제
49 이항 로지스틱 회귀: 반복 한도 내 수렴 실패
50 다항 로지스틱 회귀: 반복 한도 내 수렴 실패
36, 48, 49, 50은 요청에 따라 재구현하지 않고 고정 제외했습니다.
자료 조건으로 제외되는 항목은 필터 범위에 따라 달라집니다.

데이터와 계산
- 분석은 브라우저의 JS로 실행합니다. Python 서버나 외부 API는 사용하지 않습니다.
- data.js는 제공된 엑셀의 스냅샷입니다. 원본 엑셀 변경은 자동 반영되지 않습니다.
- 전체 원장 및 선택한 거래를 보유한 날짜 범위에서 계산합니다.
- 많은 집단 비교는 기준에 따라 건수가 가장 많은 두 집단 또는 전체 집단을 사용합니다.
  실제 비교 대상은 각 분석 카드의 설명에 표시합니다.
- 순열과 모의계산에는 고정된 난수 시드와 반복 한도를 사용합니다.
- 대규모 거리/군집/일부 모형은 명시된 표본 또는 고정 사양으로 계산합니다.
  그래프의 점 표시 축소와 실제 추정 표본 축소는 각각 설명에 적습니다.
- 가상 원장입니다. 관찰된 연관성을 실제 사업의 인과관계로 해석하지 않습니다.
- 매출액에서 매입액을 뺀 차액은 이익 또는 현금흐름이 아닙니다.

검증
원본 건수와 합계, 주요 통계 불변조건, 모형 출력의 유한값,
96개 결과의 존재, 모든 분석 상세 그래프, 부서 필터, 빈 범위,
페이지 이동, 모바일 가로 넘침, 외부 네트워크 요청 없음 등을 확인했습니다.
Chrome file:// 환경에서 전체 원장 초기 계산은 테스트 기기 기준 약 1~2초입니다.
모든 분석이 공인 통계 패키지와 전수 교차검증된 것은 아닙니다.

파일
index.html       화면 구조
styles.css       반응형 화면 디자인
app.js           화면 동작, 필터, 내보내기, 분석 실행 제어
charts.js        SVG 그래프
data.js          원장 스냅샷, 항목 목록, 출처
modules/core.js  분포, 집단 비교, 범주형 관계
modules/models.js 회귀, 이상거래, 군집, 예측
modules/temporal.js 시계열, 재표집, 진단, 검증
